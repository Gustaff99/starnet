Modelos y proveedores

Connect a model account, API key, or local endpoint.

Bring your own key (BYOK)

StarNet talks to models through your credentials. The simplest path is an OpenRouter API key: one key, hundreds of models, transparent per-token pricing. Paste it once in Settings and every agent can use any model you allow.

Supported providers

The provider picker is a first-class roster, not one generic endpoint wearing different labels:

  • Account sign-in: ChatGPT (Codex), Grok, Kimi for Coding, and Claude CLI. These use the provider's sign-in flow (for Claude CLI, your existing Claude Code sign-in) instead of asking you to paste an API key.
  • Direct API keys: OpenRouter, OpenAI, Anthropic, Google Gemini, xAI, Groq, Mistral, DeepSeek, Together AI, Fireworks AI, Perplexity, and Cerebras.
  • Local and custom: Ollama on your machine, or any custom endpoint that speaks the OpenAI-compatible wire format.
Release note: these docs track current source. The stable installer linked from the site can lag while the next Windows and macOS builds pass signing and notarization.

StarNet account

If STARNET is offered on the first-run connection screen, select it and choose CONNECT STARNET ACCOUNT. Confirm the short code in your browser, then return to the app and check its connection status before continuing.

Model choice and account plans

Change an individual agent’s model in CREW › AGENTS, in its dossier. Reasoning effort, when supported by that model, is a separate control; MAX is an effort setting, not a subscription plan. A model’s tier badge is an editorial rating, not an account entitlement.

The model picker’s STARNET SUBSCRIPTION link opens the pricing page in your browser. In the app’s STORE, ADD CREDITS and, when shown for an existing subscription, MANAGE PLAN also open your browser. These account actions are separate from model selection and from installing app updates through Update Center.

Where keys live

Keys are stored locally in your OS keychain via the desktop shell — never in plain project files, never sent anywhere except the provider they belong to. Provider requests leave your machine only when an agent actually runs.

Service keys (CONNECTED › API KEYS)

Beyond model providers, agents sometimes need platform keys to do real work — a Stripe test key, a GitHub token, a search API key. CONNECT › ABILITIES › CONNECTED › API KEYS lets you paste any service key; StarNet exposes it to agent runs as an environment variable and tells the agent only the name of what's available, never the value. The key itself never enters the model prompt. The key field also takes a 1Password reference (op://vault/item/field), read through the 1Password CLI and kept only in memory.

Cost honesty

SETTINGS › SPENDING LIMITS shows what you have spent. Runs on StarNet credits and runs on your own provider key are billed separately. If a run stopped before StarNet recorded what it cost, it is listed there as INTERRUPTED. If StarNet also didn't record which account paid for it, the row says BILLING SOURCE UNKNOWN. StarNet never guesses the amount: enter the verified charge and press SETTLE. If you set a spending limit yourself, paid runs are refused until those runs are settled.
