Instalación y primera tarea

// desde la descarga hasta tu primer agente funcional

1. Descargar e instalar

Descarga StarNet para Windows o macOS desde la página de versiones:

PlataformaArchivo
Windows 10 / 11 (64-bit)StarNet_<version>_x64-setup.exe
macOS — Apple Silicon (M1 o posterior)StarNet_<version>_aarch64.dmg
macOS — IntelStarNet_<version>_x64.dmg

¿No sabes qué Mac tienes? Menú Apple → Acerca de este Mac. "Apple M…" significa Apple Silicon; "Intel" significa Intel. Si eliges el equivocado, no funcionará.

Primer arranque en Windows

Abre el instalador y sigue sus pasos. Si SmartScreen muestra "Windows ha protegido tu PC", abre Más información, verifica que el editor coincide con las notas de la versión, y continúa solo entonces.

Primer arranque en macOS

  1. Abre el .dmg y arrastra StarNet a Aplicaciones.
  2. Abre StarNet desde Aplicaciones.

Si Gatekeeper informa de un desarrollador desconocido, falta de notary o una app dañada, detente y informa del tag de la versión y el nombre del archivo. No quites la cuarentena de una supuesta versión pública.

2. Conectar un proveedor

El primer arranque tiene dos pasos de configuración: elige la identidad de tu agente y luego conecta su modelo. Usa una cuenta de StarNet, un inicio de sesión de proveedor soportado, una clave API o un modelo local. La referencia de modelos y proveedores explica cada opción.

Selecciona un modelo antes de continuar. Tu proveedor o modelo local debe estar disponible para que el agente responda.

3. Envía tu primera tarea

Your first crew member is the Overseer. Talk to it in COMMS, the station’s chat window.

  1. Finish the introduction and open your agent’s COMMS conversation.
  2. Send a small request, such as “Give me a three-item checklist for planning my week.”
  3. Espera la respuesta completa. Si el proveedor devuelve un error, revisa tu conexión de modelo antes de intentar una tarea mayor.

That is enough to start using StarNet. When you want work to pass through several agents, follow Crea tu primer flujo. To give your crew more tools, see Configura tu equipo.

4. Actualizaciones

Use the desktop app’s Update Center to check for and install updates. If an update cannot complete, follow the troubleshooting guide and note the version and error shown.

Ejecutar desde código fuente

Para un checkout de desarrollo, instala Node.js 18 o posterior, y luego ejecuta:

git clone https://github.com/androoAGI/starnet.git
cd starnet
npm install
npm start
# open http://localhost:8787

Keep that terminal running while you use the station. The desktop installer is the simpler path if you do not need a source checkout. For speech setup and fallbacks, see Agentes, equipos y voz.
